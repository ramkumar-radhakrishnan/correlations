B. COLOUR: the index order inside B_2
   B^{bc}_{2ji}(k+,-w; p+,-z) carries { rho^c(y), rho^b(x) } : FIRST index -> rho(x),
   SECOND index -> rho(y).  So Bbar^{ca} -> U^{ce}(x) U^{ad}(y) { rho^d(y), rho^e(x) },
   and  -U^{bc}(z) Bbar^{ca} = -U^{bc}(z) U^{ce}(x) U^{ad}(y) {rho^d(y),rho^e(x)}   MATCHES
   term 1: U^{ac}(w) B^{bc} = U^{ac}(w) {rho^c(y), rho^b(x)}                       MATCHES
   note term 1 carries NO U(z) at all.
