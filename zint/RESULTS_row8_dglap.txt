============================================================================
1.  THE SPLITTING VARIABLE
============================================================================
   A^dagger creates ONE gluon of light-cone momentum  S = p+ + k+  from rho.
   C splits it into the measured gluon (k+) and the unobserved one (p+).
   So the DGLAP variable is the measured daughter's fraction of the PARENT:
       zeta = k+/(p+ + k+),   zetabar = p+/(p+ + k+),   zeta + zetabar = 1
   NOT xi = p+/k+.  In these variables  a = S/p+ = 1/zetabar,  b = S/k+ = 1/zeta.

============================================================================
2.  THE BRACKET IN zeta -- and why the 2/k+ term dies
============================================================================
   c1 = d_perp - 2/zetabar - 2/zeta ,  c2 = 1/zeta^2 + 1/zetabar^2 ,  c3 = 2/(zeta zetabar)
   after int d^2z the tensor T^{mm'} is SYMMETRIC, so c1 and c3 contract identically:
       c1 + c3 = d_perp    <- exactly d_perp, because
       2/(zeta zetabar) - 2/zeta - 2/zetabar = 2[1 - zeta - zetabar]/(zeta zetabar) = 0
   the cancellation IS the momentum sum rule zeta + zetabar = 1.

============================================================================
3.  z INTEGRATED FIRST, IN d = 2 - 2 eps
============================================================================
   T^{mm'} = C(eps)(r^2 mu^2)^{-eps} [ delta^{mm'}/(2 eps) - rhat^m rhat^{m'} ]
   delta_km delta_k'm' , delta_km' delta_k'm  ->  T^{kk'} X^k X'^k'  = Tc [X/(2eps) - R]
   delta_mm' delta_kk'                        ->  (tr T) (X.X')      = Tc (d/(2eps) - 1) X
   with d_perp = 2 - 2 eps :  d_perp/(2 eps) = 1/eps - 1 ,  d/(2eps) - 1 = 1/eps - 2
   longitudinal x transverse, before expanding:
      (-X*(2*epsilon - 1)*(zeta**2 + (zeta - 1)**2) + zeta*(2*R*epsilon - X)*(zeta*(1 - zeta) + zeta*(epsilon - 1)*(zeta - 1)**2 + zeta + (zeta - 1)**2 - 1))/(epsilon*zeta**2*(zeta - 1)**2)

5.  THE SPLITTING FUNCTION
============================================================================
   C_UV(zeta) = zeta/zetabar + zetabar/zeta + zeta zetabar = (-zeta**2 + zeta*(zeta - 1)*(-zeta**2 + zeta - 1) + zeta - 1)/(zeta*(zeta - 1))  = P_gg/(2 Nc)
   also      = zeta zetabar + 1/(zeta zetabar) - 2 : True

   DIFFERENCE            : X*(zeta**4 - 2*zeta**3 + 3*zeta**2 - 2*zeta + 1)/(zeta**3*(zeta - 1))
   non-log remainder     : -(Lcal*X*zeta**4 - 2*Lcal*X*zeta**3 + 3*Lcal*X*zeta**2 - 2*Lcal*X*zeta + Lcal*X - 2*R*zeta**4 + 4*R*zeta**3 - 2*R*zeta**2 + X*zeta**4 - 2*X*zeta**3 + X*zeta**2)/(zeta**3*(zeta - 1))

8.  THE zeta INTEGRAL AND ITS TWO ENDS
============================================================================
   dp+ = k+ d zeta / zeta^2   (at fixed k+, since S = k+/zeta)
   integrand C_UV/zeta^2 = -1 - 1/(z - 1) + 2/z - 1/z**2 + z**(-3)
   primitive             = -z + 2*log(z) - log(z - 1) + 1/z - 1/(2*z**2)
   evaluated on  zeta in [k+/V , k+/(k+ + Lambda)] :
      (V*(-Lambda**3 - Lambda**2*kplus + Lambda*V**2 + Lambda*kplus**2 + V**2*kplus - kplus**3) + 2*kplus*(-Lambda*V**2 + Lambda*V*kplus*log(-V + kplus) - I*pi*Lambda*V*kplus + Lambda*kplus**2 - V**2*kplus + V*kplus**2*log(-V + kplus) - I*pi*V*kplus**2 + kplus**3 + log(V**(V*kplus*(Lambda + kplus))/(Lambda**(V*kplus*(Lambda + kplus))*(Lambda + kplus)**(V*kplus*(Lambda + kplus))))))/(2*V*kplus**2*(Lambda + kplus))

   zeta -> 1 end (p+ -> 0):  -log(1-zeta) -> log(k+/Lambda) = the RAPIDITY log
   zeta -> 0 end (p+ -> V):  1/zeta^3 -> V^2/(2 k+^2), the known kinematic growth

   and the classic sum rule, C_UV integrated over the full range:
      int_0^1 [ zeta zetabar + 1/(zeta zetabar) - 2 ] d zeta = 1/6 - 2 + (rapidity logs)
      1/6 - 2 = -11/6  ->  2 l_k - 11/6 ;  x 2Nc  ->  4 Nc l_k - 11Nc/3 = -b0

c1 + c3 = 2    (= d_perp; the 2/k+ term is gone)
full - (C_UV Lcal X + zeta zetabar [X-2R])/k+^2 = 0
coefficient of Lcal in full, x k+^2 : -X*(zeta**2 - zeta + 1)**2/(zeta*(zeta - 1))  = C_UV(zeta) X : True
P_gg(zeta)/(2 Nc) = C_UV : -(zeta**2 - zeta + 1)**2/(zeta*(zeta - 1))

PRIMITIVE of C_UV(zeta)/zeta^2 :
   F(zeta) = -zeta + 2*log(zeta) - log(1 - zeta) + 1/zeta - 1/(2*zeta**2)      dF/dzeta - C_UV/zeta^2 = 0

   upper end zeta+ = k+/(k+ + Lambda), small Lambda : log(kplus/Lambda) - 1/2
   lower end zeta- = k+/V                           : -V**2/(2*kplus**2) + V/kplus + log(kplus**2/V) - log(V - kplus) - kplus/V

   => int = log(k+/Lambda) - 1/2 + 2 log(V/k+) - V/k+ + V^2/(2 k+^2)

   if instead p+ <= k+ (i.e. zeta >= 1/2, the measured gluon the harder one):
      F(1/2) = -log(2) - 1/2
      int_{1/2}^{zeta+} = log(k+/Lambda) + log 2 = log(2 k+/Lambda)   -- finite, no V
