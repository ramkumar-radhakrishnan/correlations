A. SHORT DISTANCE.  small disc about each singular point
   near z = y' :  numerator -> (y'-z).(x-y') = O(rho), denominator = rho^2 (x-y')^2
   so the integrand is O(1/rho) and, the leading piece being odd, the disc
   integral should go as eps^2:
   z -> y'  eps=1e-01:  |F| = 1.5123e-17
   z -> y'  eps=1e-02:  |F| = 2.9150e-18   ratio 0.1927
   z -> y'  eps=1e-03:  |F| = 8.7532e-19   ratio 0.3003
   z -> x   eps=1e-01:  |F| = 1.1501e-17
   z -> x   eps=1e-02:  |F| = 1.1138e-18   ratio 0.0968
   z -> x   eps=1e-03:  |F| = 8.8850e-20   ratio 0.0798
   -> ~0.01 per decade, F ~ eps^2.   NO ULTRAVIOLET DIVERGENCE.

B. EXACT CLOSED FORM.  In complex coordinates K = Re 1/[(zbar-ybar')(z-x)], and
   int_{|z|<R} d^2z / [(zbar-abar)(z-b)] = pi log(R^2/|a-b|^2), so
      int_{|z|<R} d^2z K  =  pi log( R^2 / (y'-x)^2 )   exactly, no extra constant.
   R=    20.0:  quad +17.271015    pi log(R^2/(y'-x)^2) = +17.268607
   R=   100.0:  quad +27.381075    pi log(R^2/(y'-x)^2) = +27.381004
   R=   500.0:  quad +37.493378    pi log(R^2/(y'-x)^2) = +37.493400
   R=  2000.0:  quad +46.203719    pi log(R^2/(y'-x)^2) = +46.203745
   |y'-x| = 1.280625

C. READING IT OFF
   * the ONLY short-distance scale in the answer is |y'-x|, an EXTERNAL separation.
     No regulator appears -> no UV divergence, nothing to renormalise.
   * the R dependence is 2 pi log R : the divergence is INFRARED, coefficient 2 pi,
     matching the slope +6.28319 measured earlier for this structure.
   * the log(1/(y'-x)^2) is the y' -> x singularity.  At exactly y' = x the kernel
     degenerates to 1/(x-z)^2 and the z-integral IS log divergent at z -> x;
     but that is a set of measure zero and log^n is integrable against d^2(y'-x):
      |y'-x| = 1e-02 :  pi log(R^2/(y'-x)^2) at R=100 =   +57.8703   (grows only logarithmically)
      |y'-x| = 1e-04 :  pi log(R^2/(y'-x)^2) at R=100 =   +86.8054   (grows only logarithmically)
      |y'-x| = 1e-06 :  pi log(R^2/(y'-x)^2) at R=100 =  +115.7406   (grows only logarithmically)
