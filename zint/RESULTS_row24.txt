================================================================================
1.  THE THREE CONTRACTIONS, DONE INDEX BY INDEX (numerically, d=2)
================================================================================
   delta_km delta_k'm'  ->  T^{mm'} X^m X'^m'  = T(X,X') :     0.494031134  vs     0.494031134
   delta_mm' delta_kk'  ->  (tr T)(X.X')                 :     0.006421621  vs     0.006421621
   delta_mk' delta_km'  ->  T^{mm'} X'^m X^m' = T(X',X)  :     0.494031134  vs     0.494031134
   and T symmetric => T(X',X) = T(X,X') :  diff 0.00e+00
   ==> the b1 and b3 terms carry the SAME structure and simply ADD.

================================================================================
2.  b1 + b3 : THE 2/k+ CANCELS (the momentum sum rule)
================================================================================
   b1 = (p+/S^2) c1 = (d_perp*kplus*pplus - 2*kplus**2 - 4*kplus*pplus - 2*pplus**2)/(kplus*(kplus**2 + 2*kplus*pplus + pplus**2))
        = d_perp p+/S^2 - 2/S - 2p+/(S k+)   and  2/S + 2p+/(S k+) = (2/k+)(zeta + zetabar) = 2/k+
   b3 = (p+/S^2) c3 = 2/kplus
   b1 + b3          = d_perp*pplus/(kplus**2 + 2*kplus*pplus + pplus**2)
   check  b1+b3 - d_perp p+/S^2 = 0

================================================================================
3.  THE TWO T-CONTRACTIONS IN d = 2-2eps
================================================================================
   (i)  X_m X'_m' T^{mm'} = C_eps [ Xcal/(2eps) - Rcal ]        (X, X' carry NO eps)
          ->  pi*(Lcal*Xcal - 2*Rcal + 2*Xcal)/2
   (ii) tr T = delta_mm' T^{mm'} = C_eps [ d_perp/(2eps) - 1 ] ,  d_perp = 2-2eps
          = C_eps/eps (1-eps) - C_eps = C_eps/eps - C_eps - C_eps
          ->  pi*Lcal        <-- the +2 is EATEN

================================================================================
4.  ASSEMBLE
================================================================================
   (b1+b3) T(X,X') = (2-2eps) p+/S^2 x C_eps[Xcal/2eps - Rcal]
        = (p+/S^2)[ (C_eps/eps - C_eps) Xcal - 2 C_eps Rcal ]  ->  (pi p+/S^2)[ (Lcal+1) Xcal - 2 Rcal ]
        symbolic: pi*pplus*(Lcal*Xcal - 2*Rcal + Xcal)/(kplus + pplus)**2
   b2 (tr T) Xcal  ->  pi (p+/k+^2 + 1/p+) Lcal Xcal
        symbolic: pi*Lcal*Xcal*(kplus**2 + pplus**2)/(kplus**2*pplus)

================================================================================
5.  TO zeta VARIABLES
================================================================================
   S = k+/zeta ,  p+ = (zetabar/zeta) k+  =>
     p+/S^2   = zeta zetabar / k+
     p+/k+^2  = zetabar/(zeta k+)
     1/p+     = zeta/(zetabar k+)
   Q - (pi/k+){ C_UV(zeta) Lcal Xcal + zeta zetabar [Xcal - 2 Rcal] }  =  0
   (the '+1' left over in (Lcal+1) is exactly what supplies the zeta zetabar Xcal)

   C_UV(zeta) = zeta/zetabar + zetabar/zeta + zeta zetabar = P_gg(zeta)/(2 N_c) :
     zeta=0.2 :  C_UV = 4.410000   =  zeta zetabar + 1/(zeta zetabar) - 2 = 4.410000
     zeta=0.5 :  C_UV = 2.250000   =  zeta zetabar + 1/(zeta zetabar) - 2 = 2.250000
     zeta=0.8 :  C_UV = 4.410000   =  zeta zetabar + 1/(zeta zetabar) - 2 = 4.410000

================================================================================
6.  THE p+ -> zeta MEASURE
================================================================================
   p+ = k+(1-zeta)/zeta  =>  dp+/dzeta = -kplus/zeta**2
   |dp+| = k+ dzeta/zeta^2 ;  p+=Lambda -> zeta = k+/(k+ + Lambda) ;  p+=V-k+ -> zeta = k+/V
   int_Lambda^{V-k+} dp+  =  k+ int_{k+/V}^{k+/(k+ + Lambda)} dzeta/zeta^2

   overall constant:  (1/(2pi)^3)(g^4/4pi^4)(N_c/k+) x (1/2pi) x (pi/k+) = N_c*g**4/(64*pi**7*kplus**2)
