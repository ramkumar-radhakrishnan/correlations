1.  THE MASTER z-INTEGRAL: the large-|z| end is cut by the PHASE, not divergent
==============================================================================
   In 2b the colour factor N_c[U(y)-U(x)] is z-independent, so the only z dependence
   left is the kernel and the phase.  Writing the total phase as
        exp[-i k.(w' - etabar z - eta x)]  =  e^{-i k.w'} e^{i etabar k.z} e^{i eta k.x} ,
   the z integral of the UV residue is
        Int d^2z  e^{i q.(z-x)} / (z-x)^2 ,        q = etabar k ,
   which converges at large |z| by oscillation and is log divergent only at z -> x .
   With a short-distance cutoff |z-x| > rho :  = -pi log[ q^2 rho^2 e^{2 gamma_E}/4 ] .

   rho        q                 numerical -pi log[q^2 rho^2 e^{2g}/4]
   1e-04      1.30            56.95021122               56.9502112
   1e-06      1.30            85.88534885              85.88534885
   1e-06      0.40            93.29105661              93.29105661
   -> in d = 2-2eps with MSbar:  -pi [ 1/eps + log(q^2/mubar^2) ] , mubar^2 = 4 pi mu^2 e^{-gamma_E}
      The pole is purely ULTRAVIOLET (the phase already handled large |z|).

2.  THE p+ INTEGRAL OF THE UV RESIDUE:  two moments of C_UV
==============================================================================
   I0 = Int_lam^{1-lam} C_UV d eta = -2 log(lam) - 11/6 + O(lam)
        sympy: -2*log(lamb) - 11/6
        decomposition:  Int eta etabar = 1/6 ,  each of Int eta/etabar and Int etabar/eta
                        = log(1/lam) - 1  =>  2 log(1/lam) - 2 + 1/6 = 2 log(1/lam) - 11/6

   Int eta*etabar   log(etabar^2) d eta = -5/18
   Int eta/etabar   log(etabar^2) d eta = 2*lamb*log(lamb) - log(lamb)**2 + 2
   Int etabar/eta   log(etabar^2) d eta = 2 - pi**2/3
   I1 =  2*lamb*log(lamb) - log(lamb)**2 - pi**2/3 + 67/18

   in terms of L = log(k+/Lambda) :
       I0 = 2*L - 11/6
       I1 = -L**2 - 2*L*lamb - pi**2/3 + 67/18
