### DGLAP FROM ROW IV (src/rowG2_dglap.py)

============================================================================
1.  THE BRACKET IS THE GLUON SPLITTING FUNCTION
============================================================================
   the C_1 vertex splits a parent of  S = p+ + k+  into the measured gluon (k+)
   and an unmeasured one (p+).  The measured momentum fraction is
        zeta = k+/(k+ + p+) ,   1 - zeta = p+/(k+ + p+)
   p+/(k+ + p+)^2   = zeta*(1 - zeta)  / k+
   p+/k+^2          = (1 - zeta)/zeta  / k+
   1/p+             = -zeta/(zeta - 1)  / k+

   sum x k+  = (-zeta**4 + 2*zeta**3 - 3*zeta**2 + 2*zeta - 1)/(zeta*(zeta - 1))
   zeta zbar + zbar/zeta + zeta/zbar = (-zeta**2*(zeta - 1)**2 - zeta**2 - (zeta - 1)**2)/(zeta*(zeta - 1))
   difference = 0      <-- ZERO

   and  P_gg(zeta) = 2 N_c [ zeta/(1-zeta) + (1-zeta)/zeta + zeta(1-zeta) ] , so
        p+/S^2 + p+/k+^2 + 1/p+  =  P_gg(zeta) / (2 N_c k+)

============================================================================
2.  THE MEASURE AND THE HARD SCALE
============================================================================
   p+ = k+ (1-zeta)/zeta  =>  dp+ = - k+ dzeta / zeta^2 , so
        int_Lambda^{V-k+} dp+  =  k+ int_{k+/V}^{k+/(k++Lambda)} dzeta / zeta^2
   -> the FRAGMENTATION measure  dzeta/zeta^2 .
   the phase is  exp[-i k.(y'-y) (k+ + p+)/k+] = exp[-i (k/zeta).(y'-y)]
   -> the hard factor sits at  k_perp / zeta , not k_perp .
   the Wilson lines sit at x, x', y, y' -- the PARENT positions, zeta-independent.

============================================================================
3.  CONSISTENCY WITH THE sigma = 1/zeta MASTERS
============================================================================
   C_UV(1/sigma) - [ (sigma-1)/sigma^2 + (sigma-1) + 1/(sigma-1) ] = 0
   i.e.  J1 + J2  =  int dzeta/zeta^2 e^{-i kappa/zeta} P_gg(zeta)/(2 N_c) .

============================================================================
4.  THE PLUS PRESCRIPTION IS THE DGLAP ONE
============================================================================
