A. LONGITUDINAL STRUCTURE OF THIS ROW   (xi = p+/k+, in units of 1/k+)
   1/(1+xi)   poles at xi = [-1]       inside [0,1]: []
   -1/xi      poles at xi = [0]        inside [0,1]: [0]
   -1         poles at xi = []         inside [0,1]: []
   -> the only singularity in the physical range is xi -> 0, the SOFT endpoint.
      No xi -> 1 pole: no collinear endpoint.

B. WHY -- the vertex's collinear denominator is switched off by the routing
   C's third term carries k+/(k+ - p+), a genuine 1/(1-xi) collinear pole.
   But C is used with first argument K+ = p+ + k+, so it becomes
      K+/(K+ - p+) = (kplus + pplus)/kplus  -- finite for every p+ > 0.

C. COMPARE WITH THE SPLITTING FUNCTION
   C_UV(xi) = P_gg/(2N_c) = xi(1-xi) + xi/(1-xi) + (1-xi)/xi
      poles at xi = [0, 1]   <- BOTH endpoints, 0 AND 1
   this row      = -1/xi          poles at xi = [0]   <- soft endpoint only
   the xi(1-xi) and xi/(1-xi) pieces of P_gg are simply absent here.
