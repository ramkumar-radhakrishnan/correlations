PART II  --  d = 2-2eps BY FEYNMAN PARAMETERS
================================================================================
 II.1  the Feynman trick   1/(AB) = int_0^1 dx /[xA+(1-x)B]^2
       int_0^1 dx/[xA+(1-x)B]^2 - 1/(AB)  =  0

 II.2  the Euclidean master  I_n = int d^d l /(l^2+Delta)^n = pi^{d/2} Gamma(n-d/2)/Gamma(n) Delta^{d/2-n}
       d=1 n=2 :  radial pi/(2*Delta**(3/2))       formula pi/(2*Delta**(3/2))       diff 0
       d=3 n=2 :  radial pi**2/sqrt(Delta)         formula pi**2/sqrt(Delta)         diff 0
       d=3 n=3 :  radial pi**2/(4*Delta**(3/2))    formula pi**2/(4*Delta**(3/2))    diff 0
       d=5 n=4 :  radial pi**3/(12*Delta**(3/2))   formula pi**3/(12*Delta**(3/2))   diff 0

 II.3  int d^d l  l^2/(l^2+Delta)^2 = I_1 - Delta I_2 = pi^{d/2} (d/2) Gamma(1-d/2) Delta^{d/2-1}
       I_1 - Delta I_2 - pi^{d/2}(d/2)Gamma(1-d/2)Delta^{d/2-1}  =  0

 II.4  the x integral
       int_0^1 dx [x(1-x)]^{-eps} = Integral(1/(x**epsilon*(1 - x)**epsilon), (x, 0, 1))   (= Beta(1-eps,1-eps))
       = Gamma(1-eps)^2/Gamma(2-2eps) = 1/(1-2eps) exactly?  (2**(2*epsilon)*sqrt(pi)*gamma(1 - epsilon)/2 - pi**2*epsilon**4*gamma(1/2 - epsilon)/3 - 2*epsilon**4*gamma(1/2 - epsilon)*zeta(3) + 8*epsilon**4*gamma(1/2 - epsilon) + epsilon**3*gamma(1/2 - epsilon)*zeta(3) + pi**2*epsilon**2*gamma(1/2 - epsilon)/12 - gamma(1/2 - epsilon)/2)/gamma(3/2 - epsilon)
       series: 1 + 2*epsilon + 4*epsilon**2 - pi**2*epsilon**2/6 + O(epsilon**3)

 II.5  the normalisation N(eps) = Gamma(1+eps) Gamma(1-eps)^2/Gamma(2-2eps)
       N(eps) = 1 + epsilon*(2 - EulerGamma) + O(epsilon**2)
       C_eps/eps  = pi*(epsilon*(-log(pi*mu2*r2) - EulerGamma + 2) + 1)/epsilon
       i.e.  pi[ 1/eps + 2 - gamma_E - log(pi mu^2 r^2) ]

================================================================================
PART III  --  MATCHING, MS-BAR, AND THE '+2 GETS EATEN' TRAP
================================================================================
 III.1 matching:  log(R^2/r^2) + 1  =  1/eps + 2 - gamma_E - log(pi mu^2 r^2)
        => log R^2 = 1/eps + 1 - gamma_E - log(pi mu^2)   and the rhat rhat parts agree EXACTLY
 III.2 MS-bar:  1/eps_MSbar = 1/eps - gamma_E + log 4pi  =>
        1/eps + 2 - gamma_E - log(pi mu^2 r^2) = 1/eps_MSbar + 2 - log(4 pi^2 mu^2 r^2) = Lcal + 2
        with  Lcal = 1/eps_MSbar - log(4 pi^2 mu^2 r^2)

 III.3 THE TRAP.  T^{mm'} = (pi/2)(Lcal+2) delta^{mm'} - pi rhat^m rhat^{m'}  is ONLY safe
       when contracted with eps-INDEPENDENT tensors.  Contract with delta_{mm'} in d=2-2eps:
         tr T = (pi/2)(Lcal+2) d_perp - pi   with d_perp = 2-2eps :  pi*(-(Lcal + 2)*(epsilon - 1) - 1)
         but Lcal contains 1/eps, so -2 eps x (pi/2) x (1/eps) = -pi is a FINITE leftover:
         tr T = pi(Lcal+2) - pi - pi = pi Lcal     <-- the +2 is eaten
       whereas  X_m X'_m' T^{mm'} = (pi/2)(Lcal+2) Xcal - pi Rcal   keeps its +2,
       because X, X' carry no eps.  Getting this wrong shifts the finite part.
