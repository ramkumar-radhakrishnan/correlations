==============================================================================
2.  WHERE A UV POLE *DOES* APPEAR -- and why it is spurious
==============================================================================
  The trace is usually evaluated by writing  u.v = (u^2 + v^2 - r^2)/2 :

      int d^dz (u.v)/(u^2 v^2) = (1/2)[ int d^dz/v^2 + int d^dz/u^2 ] - (r^2/2) G(1,1)

  Taken apart, BOTH pieces are UV divergent at z -> y (and z -> y'):
    * the scaleless tadpole  int d^dz/u^2  is  pi[ 1/eps_IR - 1/eps_UV ] = 0  only
      because its UV and IR poles are set equal -- it is not actually finite;
    * the bubble  G(1,1) = int d^dz/(u^2 v^2)  goes as  rho^{d-3} drho  at z -> y,
      i.e. it IS log UV divergent at d = 2.
  The two spurious 1/eps_UV's cancel between them, leaving the net 1/eps_IR that part 1
  measured directly.  The physical integrand (u.v)/(u^2 v^2) ~ 1/rho at z -> y is
  integrable, exactly as the numbers in 1(a) show.
  bubble  G(1,1) =  -2**(2*epsilon + 1)*pi**(5/2 - epsilon)*r2**(-epsilon - 1)/(sin(pi*epsilon)*gamma(1/2 - epsilon))
  -(r^2/2) G(1,1) = pi**(5/2 - epsilon)*(4/r2)**epsilon/(sin(pi*epsilon)*gamma(1/2 - epsilon))    <- this 1/eps is 1/eps_UV

3.  MS-BAR
==============================================================================
   C(eps) * (e^gE/4pi)^eps * (r^2 mu^2)^{-eps} / eps  =
       pi*(epsilon*(2 - log(4*pi**2*mu**2*r2)) + 1)/epsilon
      = pi [ 1/eps + 2 - log(4 pi^2 mu^2 r^2) ]  : True

   CDR / MS-bar (d_perp = 2-2eps):
       (Lcal*X*kplus**2*(kplus**2 + 2*kplus*pplus + pplus**2) + Lcal*X*pplus**2*(kplus**2 + 2*kplus*pplus + pplus**2) + kplus**2*pplus**2*(Lcal*X - 2*R + X))/(kplus**2*pplus*(kplus**2 + 2*kplus*pplus + pplus**2))    [note the +2's cancelled in the delta_mm' term]

       (Lcal*X*kplus**2*(kplus**2 + 2*kplus*pplus + pplus**2) + Lcal*X*pplus**2*(kplus**2 + 2*kplus*pplus + pplus**2) + kplus**2*pplus**2*(Lcal*X - 2*R + 2*X))/(kplus**2*pplus*(kplus**2 + 2*kplus*pplus + pplus**2))

ANALYTIC LARGE-DISTANCE BEHAVIOUR  (x = R nhat, everything else fixed)
==============================================================================
   (x-y)^k/(x-y)^2  =  nhat^k/R  +  [2 nhat^k (nhat.y) - y^k]/R^2  +  O(1/R^3)

   angular averages:   <nhat^k> = 0
                       <2 nhat^k (nhat.y) - y^k> = 2 (y^k/2) - y^k = 0
   -> the first TWO orders average to zero;  the x and x' integrals converge.

   y appears in TWO kernels and in the phase:
       |integrand| ~ 1/R^2 ,   measure R^2 dR/R      -> log divergent WITHOUT the phase

   The phase is the only thing that saves y and y'.
